# Gesture Control

Управление мышью с помощью жестов руки через веб-камеру.

## Возможности

* Управление курсором указательным пальцем
* Зажатие и удержание ЛКМ
* Перетаскивание объектов
* Вертикальный скролл
* Горизонтальный скролл
* Распознавание жестов в реальном времени
* Использование собственной модели MediaPipe

## Технологии

* Python 3.10
* MediaPipe
* MediaPipe Model Maker
* OpenCV
* PyAutoGUI

## Жесты

| Жест     | Действие                             |
| -------- | ------------------------------------ |
| `MOVE`   | Движение курсора                     |
| `CLICK`  | Зажатие ЛКМ + движение курсора       |
| `SCROLL` | Вертикальный и горизонтальный скролл |

Названия жестов должны соответствовать названиям классов в обученной модели.

## Настройки

Основные параметры:

```python
SMOOTHING = 0.2
SCROLL_SPEED = 500
SCROLL_DEAD_ZONE = 0.015
CLICK_HOLD_DELAY = 0.15
```

`SMOOTHING` — плавность движения курсора.

`SCROLL_SPEED` — скорость прокрутки.

`SCROLL_DEAD_ZONE` — минимальное движение для начала скролла.

`CLICK_HOLD_DELAY` — задержка перед отпусканием ЛКМ после потери жеста.

## Обучение модели

Dataset должен содержать отдельную папку для каждого жеста и папку `None`:

```text
dataset/
├── MOVE/
├── CLICK/
├── SCROLL/
└── None/
```

Модель после обучения экспортируется в формате:

```text
gesture_recognizer.task
```

## Управление

```text
MOVE
  → движение указательного пальца
  → движение курсора

CLICK
  → зажать жест
  → ЛКМ остаётся зажатой
  → движение пальца перемещает курсор
  → убрать жест
  → ЛКМ отпускается

SCROLL
  → движение вверх/вниз
  → вертикальный скролл

  → движение влево/вправо
  → горизонтальный скролл
```
